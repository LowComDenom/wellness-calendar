# MVP

## Calendar UI  
Story: As a user, I want to be able to view my wellness routine notes on convenient calendar UI, so that I can understand my habits from a temporal perspective without hassle.
## CRUD for notes  
Story: As a user, I want to create, view, edit, and delete my notes, so that I can keep an accurate record of my nutrition and fitness activities.
## Nutrition and fitness note templates  
Story: As a user, I want the option to create notes from a predefined template, so that I can enter details relevant to that activity without having to build a form myself each time.
