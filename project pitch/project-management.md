# Project Management System

I'll use a GitHub project board to track work across the backend and web repositories. I'll probably be working alone so, tickets will be assigned by me to myself.

## High-Level Tickets

1. Finalize the data model and API.
2. Finalize the database schema and create a seeding script to generate mock data.
3. Implement account registration, login, and user-scoped access.
4. Implement API routes.
5. Build the calendar view and note forms.
6. Connect the web UI to the API.
7. Deploy the frontend and backend.
8. Write documentation on the backend and frontend, including a guide for how to run them.
