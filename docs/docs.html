Wellness Calendar

A cross-platform (status pending), simple lifestyle journal to help you stay accountable.

Quick Overview

MVP Features

Users will be able to create a log of their nutrition, fitness, and other activities via a polished, calendar-based UI by attaching any number of notes to a given day.

Planned Features
